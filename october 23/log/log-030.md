3. **Be present with a way to stop** (power button or Ctrl-C), arms at rest (hanging), table clear except the block.
4. **Start:** `cd ~ && OPENARM_MODEL_MAPPING=official ~/dream-env/bin/dreamcli robot up` (`workspace.py start` does the preflight first). The right arm raises itself along the 28 s path; the left stays put (lock). Wait for "station ready" in `~/.dreamlabs/station.log` (`dreamcli robot log`).
5. **Run:** Live View, model selected, Start with a prompt. Status: `curl -s 127.0.0.1:8091/status`. Run results: `~/robots-inference.jsonl` (`run_stop` lines), movement events: `python workspace/stage1.py timeline`.
6. **Stop:** `~/dream-env/bin/dreamcli robot down`. It waits 60 s for the park (28 s on the right arm). Afterwards confirm every motor is disabled (state query with `ReadOnlyArm`, as in log-029's session) and that no "did not confirm switching off" line is in the log.
